# vae-tui (Ratatui)

```bash
./install                 # builds release binary
./vae --demo              # backend + hello manifest + TUI
# or
cargo install --path tui  # installs `vae-tui` to cargo bin
```

Env: `TUI_SESSION_ID`, `TUI_WS_URL` — see `.env.example`.

Keys: `PgUp`/`PgDn` scroll, `q` quit.
